# **Методы программирования приложений**

## Определение
Методы программирования — это подходы к созданию программных приложений, определяющие структуру кода и способ взаимодействия с данными.

## **Основные методы**
- **Процедурное** — программа состоит из функций и процедур.
- **Объектно-ориентированное** (ООП) — программа строится из объектов (класс, объект).
- **Функциональное** — используется набор функций без изменения данных.
- **Событийно-ориентированное** — работа программы зависит от событий пользователя.
- **Компонентное** — приложение создаётся из независимых компонентов.
