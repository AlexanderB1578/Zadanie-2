# Библиотеки

## Понятие библиотек
Библиотека — это набор готовых функций, классов и модулей, которые используются для упрощения разработки программ.

## Виды библиотек
- Стандартные
- Сторонние
- Пользовательские

## Назначение
- Повторное использование кода
- Сокращение времени разработки
- Повышение надежности программ

## Преимущества
- Экономия времени
- Проверенный и оптимизированный код
- Удобство поддержки

## Примеры
- Math (математические функции)
- NumPy (Python)
- jQuery (JavaScript)
