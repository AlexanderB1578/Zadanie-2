# Web-приложения

## Понятие Web-приложений
Web-приложения — это программы, которые работают через браузер и используют интернет или локальную сеть.

## Архитектура
- Клиентская часть (frontend)
- Серверная часть (backend)
- База данных

## Основные технологии
- HTML, CSS, JavaScript
- PHP, Python, Java, C#
- Фреймворки (React, Angular, Django)

## Преимущества
- Доступ с любого устройства
- Не требуют установки
- Легко обновляются

## Недостатки
- Зависимость от интернета
- Требования к безопасности

## Примеры
- Интернет-магазины
- Социальные сети
- Онлайн-сервисы
